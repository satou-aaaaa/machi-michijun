# 町の道順

地図で見た道順を覚えて、同じ道をたどる頭の体操のゲームです。曲がる角には郵便局・パン屋などの目印があり、「パン屋の角を右」のように目印で覚えます。

- 遊ぶ: https://satou-aaaaa.github.io/machi-michijun/
- 今日の道（曲がる角2・3・4つ）はだれでも同じで1日1回。最後に1本目の道で曲がった角の目印を思い出します。
- 上級（曲がる角5・6つ、道のりのことばなし）・練習（何回でも）・とことん（一度で歩けるたびに曲がる角が1つふえる）。
- 高齢の人も遊びやすいように、文字の大きさ3段・押すだけ・時間制限なし。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、別の端末へ記録を移す引き継ぎコードがあります。
- 記録は遊ぶ人のブラウザの中だけ。外へ何も送りません。

## このゲームについて（言い方の決まり）

頭を使う習慣づくりのためのゲームです。医療機器ではなく、認知症を予防したり治したりするものではありません。

- WHO の指針（2019年）は、頭の訓練を「勧めてもよい」としていますが、根拠の確かさは「とても低い〜低い」です。出典: [WHO 2019](https://www.who.int/publications/i/item/9789241550543)
- 認知症の危険を下げると考えられているのは、運動・血圧・禁煙・聞こえ・人との交流など暮らし全体の習慣です。出典: [Lancet 委員会 2024](https://doi.org/10.1016/S0140-6736(24)01296-0)
- 画面の中で道を探す練習を続けた人は海馬の大きさが保たれていた、という小さな研究があります。人数が少なく、病気を防げるかは分かっていません。出典: [Lövdén ほか 2012](https://pubmed.ncbi.nlm.nih.gov/21497950/)
- 道を覚えるときに目印を手がかりにする方法と年齢の研究: [PMC6048192](https://pmc.ncbi.nlm.nih.gov/articles/PMC6048192/)
